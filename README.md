# Expense Tracker

**Автор:** [Максютов Нургиз]
**Язык:** Python 3.x

## Описание

GUI-приложение «Expense Tracker» для отслеживания личных расходов с фильтрацией, подсчётом суммы за период, JSON и Git.

## Возможности

*Создана форма с полями: Сумма, Категория (например, еда, транспорт, развлечения), Дата
*Добавлена кнопка «Добавить расход», которая добавляет запись в таблицу.
*Реализуетсяподсчёт суммы расходов за выбранный период.
* Фильтрацию: По категории, По дате
